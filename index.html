jQuery Selectors Used

#clickButton
The ID selector selects the button with the ID "clickButton". It is used with the click event to change the text of the paragraph.
#doubleClickParagraph
The ID selector selects the paragraph with the ID "doubleClickParagraph". It is used with the double-click event to change the paragraph style.
#hoverBox
The ID selector selects the box with the ID "hoverBox". It is used with the hover event to change the appearance of the box.
